Como colocar online no GitHub Pages:

  1. Entra na tua conta no GitHub.com e clica em New (Novo Repositório).
  2. Dá um nome ao repositório (ex: sueca-online), deixa como Public e cria-o.
  3. Clica em uploading an existing file e arrasta o ficheiro index.html que acabaste de transferir. Clica em Commit changes.
  4. Vai ao separador Settings (Definições) do repositório e, no menu lateral esquerdo, clica em Pages.
  5. Em Branch, seleciona main (pasta / (root)) e clica em Save.
  6. Após 1 a 2 minutos, o GitHub mostra o link público do teu jogo no topo dessa página!
